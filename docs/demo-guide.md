# Five-minute Nigraan demonstration

Use the resettable fictional Bismillah Distributors company. All evaluation is synthetic; actual pilot savings and customer traction have not been established.

| Time | Show | Explain |
| --- | --- | --- |
| 0:00–0:30 | Payment run summary | Who prepares and approves SME payments, and why payment risk and cash reserves need one view. State that the company and dataset are fictional. |
| 0:30–1:10 | Reset/load week, flagged invoices | Let the real API finish; point to line counts, blocked amount and reserve outcome returned by the system. |
| 1:10–2:20 | One blocked case | Show the highest-priority reason, original invoice evidence, verification step and audit trace. Distinguish calibrated ML score from the optional generated explanation. Use Roman Urdu if it helps the audience. |
| 2:20–3:00 | Owner decision and approval | Explain independent approval and owner limits. Record an outcome; original evidence remains visible. Retraining is asynchronous and can take longer than this segment, so show completion only when the job finishes. |
| 3:00–3:40 | Upload and vendor match | Use the provided resent invoice to show real duplicate detection. Explain per-field confidence and the confirm-before-scoring gate; show vendor matching if asked. |
| 3:40–4:20 | Cash outlook | Select a week on the chart, then move a collection in What-if. Explain facts, model estimates and assumptions; the scenario does not edit the books. |
| 4:20–5:00 | Dashboard and evaluation | Show baseline comparison, measurement period and synthetic hold-out. State the first buyer and workflow, then the next evidence needed from SME pilots. |

## Before presenting

- Verify live frontend/API links and insert them in README only after checking them; add the actual recording URL.
- Test login, reset/load, flagged case, evidence tabs, role changes, approvals, upload, cash scenario and dashboard on the presentation device.
- If demonstrating Gemini, test with configured credentials beforehand. Otherwise identify the honest template/PDF/OCR fallback.
- Keep a recording of the verified flow as a connectivity backup. Do not add simulated live activity.
- Test sidebar collapse/expand, mobile navigation and reduced motion; preserve keyboard focus and readable contrast in both themes.
- Bank export contains masked account details and is a demo artifact. Export does not settle money; do not claim a working bank integration.

## Evidence to bring

Bring documented SME interviews or an authorized pilot, anonymized invoice examples where permitted, and a clearly identified buyer. Separate observed results from hypotheses about pricing, time savings and ROI. No interview, deployment, traction or revenue claim should be inferred from the synthetic demo. The judging rubric should guide the final emphasis once it is available.
